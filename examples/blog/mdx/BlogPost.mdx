      ## Why Better-MDX?

      Traditional static site generators force you to choose between:

      - **Static content** that's easy to write but limited in functionality
      - **Dynamic content** that's powerful but complex to maintain

      Better-MDX bridges this gap by offering:

      ### Template Interpolation

      <CodeBlock language="mdx">
      {`function Example() {
        const data = { users: 1250, growth: 23.5 };

        return (
          We have {{ data.users }} users with {{ data.growth }}% growth!
        )
      }`}
      </CodeBlock>

      ### Conditional Rendering

      <CodeBlock language="mdx">
      {`{user.isPremium && (
        ## Premium Features ✨
        Access exclusive content and advanced features.
      )}

      {!user.isPremium && (
        [Upgrade to Premium](/upgrade) to unlock more features.
      )}`}
      </CodeBlock>

      ### React Component Integration

      <CodeBlock language="mdx">
      {`<InteractiveChart
        data={salesData}
        type="line"
        onDataPointClick={handleClick}
      />

      <Button onClick={() => exportData()}>
        Export Data
      </Button>`}
      </CodeBlock>

      ## Getting Started

      Setting up your first Better-MDX project takes less than 5 minutes:

      <CodeBlock language="bash">
      {`# Create new project
      npx better-mdx init my-blog
      cd my-blog

      # Install dependencies
      npm install

      # Start development server
      npm run dev`}
      </CodeBlock>

      ## Advanced Features

      ### Hot Module Replacement

      Better-MDX includes built-in HMR that updates your content in real-time:

      - **Instant updates** when you save MDX files
      - **Error overlay** for compilation issues
      - **State preservation** during development

      ### Type-Safe Context

      Pass typed data to your MDX files:

      <CodeBlock language="typescript">
      {`interface BlogContext {
        user: User;
        posts: Post[];
        settings: AppSettings;
      }

      const result = engine.execute(compiled, context as BlogContext);`}
      </CodeBlock>

      ### Performance Optimization

      - **Automatic caching** of compiled templates
      - **Lazy loading** of heavy components
      - **Bundle optimization** for production builds

      ## Best Practices

      ### 1. Organize Your Content

      Structure your MDX files logically:

      ```
      mdx/
      ├── blog/
      │   ├── posts/
      │   └── categories/
      ├── pages/
      │   ├── about.mdx
      │   └── contact.mdx
      └── components/
          ├── layouts/
          └── widgets/
      ```

      ### 2. Use TypeScript Effectively

      Leverage TypeScript features in your MDX:

      <CodeBlock language="mdx">
      {`interface Product {
        id: string;
        name: string;
        price: number;
      }

      function ProductList() {
        const products: Product[] = getProducts();

        return (
          {{ products.map(product => `
            **${product.name}** - $${product.price.toFixed(2)}
          `).join('\\n') }}
        )
      }`}
      </CodeBlock>

      ### 3. Component Reusability

      Create reusable components for common patterns:

      <CodeBlock language="tsx">
      {`// src/components/InfoBox.tsx
      interface InfoBoxProps {
        type: 'info' | 'warning' | 'error';
        children: React.ReactNode;
      }

      export function InfoBox({ type, children }: InfoBoxProps) {
        return (
          <div className={`info-box info-box--${type}`}>
            {children}
          </div>
        );
      }`}
      </CodeBlock>

      ### 4. Testing Your Content

      Write tests for your MDX files:

      <CodeBlock language="typescript">
      {`import { createMDXTest } from 'better-mdx/testing';

      const test = createMDXTest('Blog post renders', blogPostContent)
        .withContext({ user: mockUser })
        .expectContains('Welcome back')
        .build();`}
      </CodeBlock>

      ### E-commerce Product Page

      <CodeBlock language="mdx">
      {`function ProductPage() {
        const { product, reviews, recommendations } = useProduct();

        return (
          # {{ product.name }}

          <ProductGallery images={product.images} />

          **Rating:** {{ product.averageRating }}/5 ({{ reviews.length }} reviews)

          {product.inStock && (
            <AddToCartButton productId={product.id} />

          \`).join('\\n') }}
        )
      }`}
      </CodeBlock>

      <CodeBlock language="mdx">
      {`function AdminDashboard() {

          # Admin Dashboard

            <StatCard title="Users" value={stats.users} trend={stats.userGrowth} />
            <StatCard title="Revenue" value={\`$\${stats.revenue}\`} trend={stats.revenueGrowth} />
            <StatCard title="Orders" value={stats.orders} trend={stats.orderGrowth} />
          </StatsGrid>

            *\${formatDate(alert.timestamp)}*
            \`).join('\\n') }}
          )}

          ## Recent Activity

        )
      }`}
