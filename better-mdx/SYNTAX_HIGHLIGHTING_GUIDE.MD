To create your own grammar and syntax highlighting for a custom file type, you can follow the same approach used by the TypeScript-TmLanguage repository. <cite/>

## Getting Started with TextMate Grammars

The TypeScript-TmLanguage repository provides an excellent template for creating custom language grammars. [1](#1-0)  You'll want to create YAML grammar files similar to how TypeScript defines its grammar structure.

## Core Grammar Structure

Start by examining the basic structure used in the TypeScript grammar. [2](#1-1)  Your grammar file should include:

- **Header metadata**: Name, scope name, file types, and UUID
- **Variables section**: Reusable regex patterns for common language constructs
- **Repository section**: Pattern definitions for different language elements

## Essential Components

### 1. Define Your Language Scope and File Types

Similar to how TypeScript defines its scope as `source.ts` for `.ts` files, you'll need to define your own scope name and file extensions. [3](#1-2) 

### 2. Create Pattern Variables

The TypeScript grammar uses extensive variables for pattern reuse. [4](#1-3)  You should define similar variables for your language's identifiers, keywords, operators, and other constructs.

### 3. Build Repository Patterns

The repository section contains the actual grammar rules. [5](#1-4)  You'll need patterns for:

- Statements and declarations
- Control structures
- Functions and classes
- Comments and strings
- Operators and punctuation

## Build System Setup

You'll need a build system to compile your YAML grammar into the XML tmLanguage format that editors consume. [6](#1-5)  The TypeScript-TmLanguage repository uses a TypeScript-based build system that:

- Reads YAML grammar files
- Compiles them to XML tmLanguage format
- Provides testing infrastructure for validation

## Testing Your Grammar

The repository includes comprehensive testing using baseline files that capture expected scope assignments. [7](#1-6)  You should create similar test files for your language to ensure your grammar correctly tokenizes code.

## Distribution

Once your grammar is working, you can distribute it as:
- A VS Code extension
- A Sublime Text package
- An Atom package
- Direct tmLanguage files for other TextMate-compatible editors

## Notes

The TextMate grammar system is widely supported across editors, making it an excellent choice for custom language support. Start with the TypeScript-TmLanguage repository structure as your foundation, then adapt the patterns and rules for your specific language syntax. The YAML format is much more maintainable than writing XML directly, and the build system approach ensures consistency and testability.

import * as vt from 'vscode-textmate/release/main';
import path = require('path');
import fs = require('fs');
import oniguruma = require('vscode-oniguruma');

enum GrammarKind {
    ts = 'source.ts',
    tsx = 'source.tsx'
}
const grammarFileNames: Record<GrammarKind, string> = {
    [GrammarKind.ts]: "TypeScript.tmLanguage",
    [GrammarKind.tsx]: "TypeScriptReact.tmLanguage"
};
function grammarPath(kind: GrammarKind) {
    return path.join(__dirname, '..', grammarFileNames[kind]);
}
const grammarPaths = {
    [GrammarKind.ts]: grammarPath(GrammarKind.ts),
    [GrammarKind.tsx]: grammarPath(GrammarKind.tsx)
};

const wasmBin = fs.readFileSync(path.join(__dirname, '../node_modules/vscode-oniguruma/release/onig.wasm')).buffer;
const vscodeOnigurumaLib: Promise<vt.IOnigLib> = oniguruma.loadWASM(wasmBin).then(() => {
    return {
        createOnigScanner(patterns) { return new oniguruma.OnigScanner(patterns); },
        createOnigString(s) { return new oniguruma.OnigString(s); }
    };
});

const registery = new vt.Registry({
    onigLib: vscodeOnigurumaLib,
    loadGrammar: function (scopeName: GrammarKind) {
        const path = grammarPaths[scopeName];
        if (path) {
            return new Promise((resolve, reject) => {
                fs.readFile(path, (error, content) => {
                    if (error) {
                        reject(error);
                    } else {
                        const rawGrammar = vt.parseRawGrammar(content.toString(), path);
                        resolve(rawGrammar);
                    }
                });
            });
        }

        return Promise.resolve(null);
    }
});
